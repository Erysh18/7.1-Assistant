# 7.1-Assistant
VistaPrint 7.1 Assistant is an Electron desktop app with a dark premium UI built using TailwindCSS. It generates professional, consistent client responses via GitHub Models API, featuring custom prompts, copy-to-clipboard, and streamlined customer communication.

VistaPrint 7.1 Assistant is a modern Electron desktop application designed to generate polite, courteous, and professional responses for customer interactions. The application is built with TailwindCSS for a sleek dark theme user interface and enhanced with animations. It runs in an 800×500 frameless window, making it lightweight and distraction-free.

Features

Electron-powered desktop application (cross-platform)

Dark theme UI with a premium, contemporary design using TailwindCSS and animations

Custom draggable title bar with frameless window style

AI response generator using xai/grok-3-mini hosted on GitHub Models API

Sender’s message input for pasting customer text

Custom prompt settings with save and manage functionality

Generated response panel with styled scrollable output

One-click copy functionality for generated responses

Keyboard shortcut support (Enter to generate responses)

Tech Stack

Electron for cross-platform desktop deployment

TailwindCSS for modern styling and animations

JavaScript and Fetch API for model inference requests

HTML and CSS for responsive layout optimized for 800×500 resolution

Use Case

This application is intended for customer service, sales, and design teams that require fast generation of professional and consistent client responses. It provides an intuitive interface that ensures efficiency and a consistent communication tone.
